selected work
Deep FOCUS — SMLM Super-Resolution
2025 MSc dissertation · QUB
Focal LossU-Net PyTorchSMLM CUDAThunderSTORM

Systematic comparative analysis of loss functions for single-molecule localisation microscopy. Generated a 10,000-sample synthetic dataset via ThunderSTORM, reimplemented Deep-STORM from scratch in PyTorch, and ran a controlled 4-way loss function study. Focal Loss achieved PSNR 33.8 dB vs 17–20 dB for regression baselines — a 60–100% improvement — with SSIM 0.83 and IoU@0.1 of 0.50, establishing loss function design as equally critical as architecture.
